# ไม่ถือเงินของลูกค้า

การรับหรือพักเงินแทนผู้อื่นต้องมีใบอนุญาต e-Payment ตาม พ.ร.บ.ระบบการชำระเงิน 2560 ซึ่งต้องใช้ทุน เวลา และกรรมการสัญชาติไทย ระบบจึงสั่งจ่ายจากบัญชีธนาคารของ Client Company ผ่านไฟล์ธนาคารหรือ API ธนาคารในนามลูกค้าเท่านั้น เงินไม่ผ่านบัญชีของเราในทุกกรณี ต้องให้ทนาย fintech ยืนยันก่อนเปิดเฟส 2 (M2.1)

## Considered Options

- เป็น payment facilitator ที่รับเงินแล้วจ่ายต่อ: ตัดออกเพราะต้องมีใบอนุญาตและรับความเสี่ยงเรื่องเงินลูกค้า
- ทำระบบให้ agent จ่ายเงินแทนผู้บริโภค: ตัดออกในการวางแผน เพราะแพลตฟอร์มและธนาคารปิดช่องทางนี้
