# LINE เป็นช่องทางหลัก ไม่ทำ mobile app

ลูกค้าไทยส่งบิลให้สำนักงานบัญชีทาง LINE อยู่แล้ว การให้ลงแอปใหม่เพิ่มแรงต้าน จึงใช้ LINE OA (บอทเข้ากลุ่มของ Client Company) และ LINE LIFF เป็นหน้าหลักของ Submitter และ Approver ส่วนงานของ Member ใช้เว็บ ออกแบบให้ใช้ reply message เป็นหลักเพราะไม่นับโควตา และมี email กับเว็บเป็นช่องทางสำรองเผื่อ LINE เปลี่ยนราคาหรือนโยบาย

## Consequences

ขึ้นกับนโยบายของ LINE ต้องแยก adapter `line` ให้เปลี่ยนช่องทางได้ และต้องตัดสินว่าจะใช้แบบกลุ่ม แชท 1:1 หรือทั้งสองแบบ (คำถามเปิดข้อ 3 ใน `docs/PRD.md`)
