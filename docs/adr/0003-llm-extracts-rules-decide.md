# LLM ดึงข้อมูล ส่วนโค้ดกฎเป็นผู้ตัดสิน

ผลที่มีผลทางเงินหรือภาษี (Check ผ่าน/ไม่ผ่าน, การอนุมัติ, การจ่าย) ต้องอธิบายได้ ทดสอบซ้ำได้ และให้ CPA ยืนยันได้ LLM ให้ผลไม่คงที่และถูกหลอกด้วยข้อความในเอกสารได้ จึงให้ LLM มีหน้าที่แค่ดึงข้อมูลเป็น JSON ตาม schema ส่วนการตัดสินทั้งหมดอยู่ในโค้ดของ `taxrules`, `control` และ policy engine ที่ตรงกับ `docs/TAX_RULES.md` และ Confidence คำนวณด้วยโค้ด ไม่ใช้ค่าที่โมเดลบอกเอง

## Consequences

กฎใหม่ทุกข้อต้องเขียนเป็นโค้ดพร้อม test แทนการเขียนเป็นคำสั่งใน prompt ใช้เวลามากขึ้นต่อกฎ แต่ได้ผลที่ตรวจสอบย้อนหลังได้
