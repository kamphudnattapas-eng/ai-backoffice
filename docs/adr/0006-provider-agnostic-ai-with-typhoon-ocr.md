# OCR ด้วย Typhoon OCR และ LLM ผ่าน adapter ที่สลับผู้ให้บริการได้

เอกสารไทยต้องการ OCR ที่เข้าใจภาษาไทยและตาราง Typhoon OCR ของ SCB 10X เป็น open model (Apache 2.0) ที่ออกแบบมาสำหรับเอกสารไทย รันเองผ่าน vLLM หรือเรียกผ่าน API ได้ จึงใช้เป็น OCR หลัก ส่วน LLM ที่ดึงข้อมูลเรียกผ่าน `adapters.llm` ที่ไม่ผูกกับผู้ให้บริการรายใด เพื่อเลือกโมเดลตามต้นทุนและผล eval และสลับได้โดยไม่แก้ module อื่น การเลือกครั้งสุดท้ายยืนยันด้วยผล prototype M0.5

## Consequences

ต้องมี eval ที่เชื่อถือได้ (`docs/EVALS.md`) เพราะการสลับโมเดลตัดสินจากตัวเลข ถ้ารัน Typhoon OCR เอง จะต้องมี GPU ซึ่งเป็นเงื่อนไขหนึ่งที่ทำให้แยก worker-docai เป็น service
